# Make the AI Judge Laugh: Office Jokes

One-line office joke entry for the make.fun competition
`u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`.

## The joke

> The office plant died, so facilities replaced it with a laminated photo of a plant — and a ticket to water it.

- **Length:** 110 characters (limit 1–199), single line, UTF-8, no trailing newline.
- **How it works:** a dead office plant is "fixed" by facilities with a laminated photo
  of a plant — and then the system issues a ticket to water the photograph. The
  surprise lands in the final clause; the recognition (dead plant, facilities,
  ticket queue) makes the laugh come with a wince.

## How to run

`main.ts` writes the joke to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`),
creating the output directory if needed. Node 22+ runs the TypeScript as-is:

```sh
node main.ts
```

## Files

- `main.ts` — entrypoint; writes the joke to `/output/entry.txt`.
- `NOTES.md` — the candidate jokes and the head-to-head judging that picked the winner.
- `.makefun/owner.json` — payout wallet for the entry.
